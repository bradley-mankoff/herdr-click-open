# herdr-click-open

Ctrl-click a web link, a file link or a Beads board link in a herdr pane to open it beside the conversation: a web link opens in terminal-browser, a file link in micro, and a board link shows that Bead in a terminal-browser pane of the same herdr workspace, which the plugin splits to the right when no pane there shows the board.

Copied from `~/Developer/herdr/click-open` on 2026-11-08 into a repo of its own, so both Macs install the same plugin and it can take the Beads-board click handler built under the Factory's Bead fac-qpv.7.2. It is a tool of the Human's own setup, not part of the Factory.
