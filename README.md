# herdr-click-open

Ctrl-click a web link, a file link or a Beads board link in a herdr pane to open it beside the conversation: a web link opens in terminal-browser, a file link in micro, and a board link opens that Bead in micro, in a split to the right of the clicked pane, rendered by `bd show` in the link's project. The pane shows a temporary copy, opened read-only, so nothing saved there reaches the Bead. A board link needs neither the board nor a browser.

Copied from `~/Developer/herdr/click-open` on 2026-11-08 into a repo of its own, so both Macs install the same plugin and it can take the Beads-board click handler built under the Factory's Bead fac-qpv.7.2. It is a tool of the Human's own setup, not part of the Factory.
